# 시험지 → 과제 정답표 만들기 (Claude·ChatGPT용 프롬프트)

선생님이 시험지 파일을 AI에게 주면, AI가 정답표를 앱에 붙여넣을 수 있는 모양으로 뽑아 주고
문제와 정답에 이상한 곳이 없는지 검토합니다. 앱 쪽에서는 **과제 만들기 → "정답표 한 번에 넣기"**에
붙여넣으면 월~토에 고르게 나뉘어 채워집니다(남는 문항은 월요일부터 하나씩 더).

## 쓰는 법

1. **한글(.hwp) 파일은 먼저 PDF로 저장**합니다 (한글 → 파일 → PDF로 저장하기).
   AI는 .hwp를 제대로 못 읽는 경우가 많습니다.
2. claude.ai(또는 ChatGPT)에 PDF를 올리고, 아래 프롬프트를 통째로 붙여넣습니다.
3. 결과의 **[정답표]** 부분만 복사해 앱의 "정답표 한 번에 넣기" 칸에 붙여넣습니다.
4. **[검토]** 목록은 직접 확인합니다. AI도 국어 문제를 틀리기 때문에,
   AI가 "정답이 다르다"고 해도 정답지를 자동으로 고치지 않습니다. 선생님이 판단하세요.

## 프롬프트 (아래를 그대로 복사)

```
첨부한 파일은 국어 시험지이고, 맨 뒤에 정답표가 있습니다. 모든 문항은 5지선다 객관식입니다.
아래 두 가지를 해 주세요.

1. [정답표]
   정답표를 그대로 옮겨 적어 주세요. 형식은 정확히 지켜 주세요.
   - 한 줄에 한 문항, "번호. 정답" (예: 1. 3)
   - 정답은 숫자 1~5로만 씁니다. 복수 정답은 + 로 잇습니다 (예: 7. 2+4)
   - 번호는 1번부터 빠짐없이 순서대로
   - 정답표 외의 말은 이 부분에 넣지 마세요.
   ※ 정답은 반드시 시험지 뒤의 정답표에서 옮깁니다. 직접 푼 답으로 바꾸지 마세요.

2. [검토]
   아래 항목을 확인해 문제가 있는 것만 "번호 — 무엇이 이상한지" 목록으로 알려 주세요.
   없으면 "이상 없음"이라고만 쓰세요.
   - 시험지의 문항 수와 정답표의 문항 수가 같은지
   - 정답표에 빠지거나 겹친 번호가 있는지
   - 선지가 5개가 아니거나, 선지 번호가 빠졌거나, 같은 선지가 두 번 나오는 문항
   - 발문과 선지가 맞지 않는 문항 (예: "적절하지 않은 것"을 묻는데 적절하지 않은 선지가 둘 이상)
   - 직접 풀어 본 답이 정답표와 다른 문항 — 왜 그렇게 봤는지 한 줄로
   - 지문·발문·선지의 오탈자
```

## 앱에 붙여넣을 때 받아들이는 모양

- `1. 3` · `1) ③` · `1번 3` · `1: 3` 처럼 번호가 붙어 있으면 번호대로 놓고,
  빠지거나 겹친 번호가 있으면 채우지 않고 알려 줍니다.
- 번호 없이 `3 1 5 2 4 …` 또는 `③①⑤②④…`만 있어도 됩니다 (한 칸이 한 문항).
- 복수 정답은 `2+4` 또는 `②④`.
- 요일마다 문항 번호는 1번부터 다시 셉니다. 미리보기에 "화 7문항 · 8~14번"처럼
  시험지의 원래 번호가 함께 나옵니다.
