# 수문재 과제 정답표 만들기

선생님이 준 시험지에서 **정답표를 옮겨 적고**, **6일 분배표**를 만들고, **오류를 검토**한다.
결과는 학생관리 앱의 과제 만들기 → "정답표 한 번에 넣기" 칸에 붙여넣어 쓴다.
앱이 정답표를 읽어 월~토에 나누므로, 여기서는 앱에 직접 들어가거나 저장하지 않는다.

## 1. 시험지 읽기

- PDF는 바로 읽는다.
- 한글(.hwp/.hwpx) 파일을 못 읽으면, 억지로 추측하지 말고 선생님께
  "한글에서 파일 → PDF로 저장하기로 저장해서 다시 주세요"라고 말한다.
- 모든 문항은 5지선다 객관식이다.

## 2. [정답표] — 시험지 맨 뒤 정답표를 그대로 옮긴다

형식을 정확히 지킨다. 앱이 이 형식을 읽는다.

```
1. 3
2. 1
3. 2+4
```

- 한 줄에 한 문항, `번호. 정답`
- 정답은 숫자 1~5만 쓴다. 복수 정답은 `+`로 잇는다 (`2+4`)
- 1번부터 빠짐없이 순서대로
- 이 부분에는 정답표 말고 아무 말도 넣지 않는다 (앱에 그대로 붙여넣기 때문)
- **정답은 반드시 시험지의 정답표에서 옮긴다. 직접 푼 답으로 바꾸지 않는다.**
  다르다고 생각되면 3번 [검토]에만 적는다.

## 3. [6일 분배] — 앱이 나눌 결과를 미리 보여준다

총 N문항을 월~토 6일에 고르게 나누고, 남는 문항은 **월요일부터 하나씩 더** 준다.
번호는 시험지 번호 그대로 이어진다.

- 하루 기본 = N ÷ 6의 몫, 나머지 r개는 월요일부터 r일에 하나씩 더
- 예) 40문항 → 월 1~7 · 화 8~14 · 수 15~21 · 목 22~28 · 금 29~34 · 토 35~40
- 예) 31문항 → 월 1~6 · 화 7~11 · 수 12~16 · 목 17~21 · 금 22~26 · 토 27~31

`월 7문항 (1~7번)` 처럼 요일마다 한 줄로 적는다.

## 4. [검토] — 문제가 있는 것만 적는다

`번호 — 무엇이 이상한지` 목록으로. 없으면 "이상 없음"만 쓴다.

- 시험지 문항 수와 정답표 문항 수가 같은지
- 정답표에 빠지거나 겹친 번호
- 선지가 5개가 아니거나, 선지 번호가 빠졌거나, 같은 선지가 두 번 나오는 문항
- 발문과 선지가 맞지 않는 문항 (예: "적절하지 않은 것"을 묻는데 해당 선지가 둘 이상)
- 직접 풀어 본 답이 정답표와 다른 문항 — 왜 그렇게 봤는지 한 줄로
- 지문·발문·선지 오탈자

검토는 참고용이다. 국어 문제는 AI도 틀릴 수 있으니 단정하지 말고 "확인해 보세요"로 쓴다.

## 5. 결과 전달

1. 채팅에 [정답표] · [6일 분배] · [검토]를 이 순서로 보여준다.
   [정답표]는 코드 블록에 넣어 한 번에 복사하기 쉽게 한다.
2. 작업 폴더에 `<시험지 파일 이름>_정답표.txt`로 [정답표]만 저장한다.
3. 마지막에 이렇게 안내한다:
   "앱 → 과제 만들기 → 정답표 한 번에 넣기에 [정답표]를 붙여넣고
   '월~토에 나누어 채우기'를 누르세요. [검토] 항목은 직접 확인해 주세요."
